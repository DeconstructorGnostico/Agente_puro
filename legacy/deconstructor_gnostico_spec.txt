### DECONSTRUCTOR GNÓSTICO

### Algoritmo de descomposición, validación y reconstrucción del conocimiento

Definición: El Deconstructor Gnóstico es un motor de análisis que transforma cualquier entrada —texto, problema, arquitectura, hipótesis, código o sistema— en una estructura verificable de conocimiento.

Su función no es aceptar ni rechazar información por su apariencia. Su función es descomponerla, identificar su naturaleza epistemológica, descubrir contradicciones, localizar variables desconocidas y reconstruir una solución fundamentada.

Su posición dentro de NRE–AMM–OMEGA es:

Semantic Firewall → Deconstructor Gnóstico → Multilayer Validator → Invariant Engine → Planner → Authorizer → Executor.

### 1\. Algoritmo maestro

D(x)=\\{O,F,A,H,C,V,U,K,E,R\\}

Donde:

| Símbolo | Elemento                  |
| ------- | ------------------------- |
| O       | Objetivos                 |
| F       | Hechos verificables       |
| A       | Afirmaciones              |
| H       | Hipótesis                 |
| C       | Restricciones             |
| V       | Variables                 |
| U       | Incertidumbres            |
| K       | Contradicciones           |
| E       | Evidencias                |
| R       | Relaciones y dependencias |

El algoritmo debe producir una representación estructurada antes de permitir cualquier decisión.

### 2\. Secuencia de ejecución

01

INPUT

Recepción de información.

02

Normalización semántica y estructural.

03

FIREWALL

Separación de datos e instrucciones no autorizadas.

04

Separación en hechos, afirmaciones, hipótesis y restricciones.

05

06

Identificación de relaciones y dependencias.

07

Detección de incompatibilidades y contradicciones.

08

Comprobación de procedencia y evidencia.

09

Comprobación de reglas estructurales.

10

Inferencia limitada por la evidencia disponible.

11

Construcción de una solución coherente.

12

Verificación independiente.

13

Entrega estructurada con incertidumbres explícitas.

### 3\. Código fuente ejecutable

Implementación autónoma en Python 3.11+, sin dependencias externas. El algoritmo admite entradas estructuradas, clasifica proposiciones, detecta contradicciones explícitas, analiza dependencias, evalúa evidencia y genera un informe JSON.

```python

from __future__ import annotations

import json
import hashlib
import re

from dataclasses import dataclass, asdict, field
from enum import Enum
from typing import Any

VERSION = "DECONSTRUCTOR_GNOSTICO_1.0"

# =========================================================
# 1. TAXONOMIA EPISTEMOLOGICA
# =========================================================

class EpistemicType(str, Enum):
    FACT = "FACT"
    CLAIM = "CLAIM"
    ASSUMPTION = "ASSUMPTION"
    HYPOTHESIS = "HYPOTHESIS"
    CONSTRAINT = "CONSTRAINT"
    OBJECTIVE = "OBJECTIVE"
    UNKNOWN = "UNKNOWN"

class Decision(str, Enum):
    PROCESS = "PROCESS"
    REJECT = "REJECT"
    HALT = "HALT"

@dataclass
class Proposition:
    id: str
    content: str
    kind: EpistemicType
    source: str = "UNSPECIFIED"
    evidence_ids: list[str] = field(default_factory=list)
    confidence: float | None = None
    dependencies: list[str] = field(default_factory=list)

@dataclass
class Evidence:
    id: str
    content: str
    source: str
    method: str
    independently_verified: bool = False

@dataclass
class Decomposition:
    objective: list[Proposition]
    facts: list[Proposition]
    claims: list[Proposition]
    assumptions: list[Proposition]
    hypotheses: list[Proposition]
    constraints: list[Proposition]
    unknowns: list[Proposition]
    evidence: list[Evidence]

# =========================================================
# 2. NORMALIZADOR
# =========================================================

class Normalizer:

    @staticmethod
    def normalize(value: str) -> str:

        if not isinstance(value, str):
            raise TypeError("INPUT_MUST_BE_STRING")

        value = value.strip()
        value = re.sub(r"\s+", " ", value)

        if not value:
            raise ValueError("EMPTY_INPUT")

        return value

# =========================================================
# 3. CLASIFICADOR EPISTEMOLOGICO
# =========================================================

class EpistemicClassifier:

    RULES = {
        EpistemicType.OBJECTIVE: [
            r"\bobjetivo\b",
            r"\bmeta\b",
            r"\bpropósito\b",
            r"\bfinalidad\b"
        ],
        EpistemicType.HYPOTHESIS: [
            r"\bhipótesis\b",
            r"\bsuponiendo que\b",
            r"\bpodría ser\b",
            r"\bposiblemente\b"
        ],
        EpistemicType.ASSUMPTION: [
            r"\bsuponemos\b",
            r"\basumimos\b",
            r"\bse presupone\b"
        ],
        EpistemicType.CONSTRAINT: [
            r"\brestricción\b",
            r"\blímite\b",
            r"\bdebe cumplirse\b",
            r"\bprohibido\b"
        ],
        EpistemicType.UNKNOWN: [
            r"\bdesconocido\b",
            r"\bno sabemos\b",
            r"\bse desconoce\b"
        ]
    }

    @classmethod
    def classify(cls, content: str) -> EpistemicType:

        matches = []

        for kind, patterns in cls.RULES.items():
            for pattern in patterns:
                if re.search(pattern, content, re.I):
                    matches.append(kind)
                    break

        # La ambigüedad no se convierte en hecho.
        if len(matches) > 1:
            return EpistemicType.UNKNOWN

        if matches:
            return matches[0]

        # Una afirmación sin evidencia declarada
        # no adquiere automáticamente categoría FACT.
        return EpistemicType.CLAIM

# =========================================================
# 4. MOTOR DE DESCOMPOSICION
# =========================================================

class GnousticDeconstructor:

    def __init__(self):

        self.propositions = []
        self.evidence = []
        self.contradictions = []
        self.dependencies = []
        self.audit = []

    def record(self, operation, payload):

        event = {
            "operation": operation,
            "payload": payload
        }

        serialized = json.dumps(
            event,
            sort_keys=True,
            ensure_ascii=False
        )

        event["hash"] = hashlib.sha256(
            serialized.encode()
        ).hexdigest()

        self.audit.append(event)

    def add_proposition(
        self,
        content: str,
        kind: EpistemicType | None = None,
        source: str = "UNSPECIFIED",
        evidence_ids: list[str] | None = None,
        dependencies: list[str] | None = None
    ):

        content = Normalizer.normalize(content)

        proposition = Proposition(
            id=f"P{len(self.propositions) + 1}",
            content=content,
            kind=kind or EpistemicClassifier.classify(content),
            source=source,
            evidence_ids=evidence_ids or [],
            dependencies=dependencies or []
        )

        self.propositions.append(proposition)

        self.record(
            "PROPOSITION_CREATED",
            asdict(proposition)
        )

        return proposition

    def add_evidence(
        self,
        content: str,
        source: str,
        method: str,
        independently_verified: bool = False
    ):

        evidence = Evidence(
            id=f"E{len(self.evidence) + 1}",
            content=Normalizer.normalize(content),
            source=source,
            method=method,
            independently_verified=independently_verified
        )

        self.evidence.append(evidence)

        self.record("EVIDENCE_REGISTERED", asdict(evidence))

        return evidence

    # =====================================================
    # 5. VALIDACION DE EVIDENCIA
    # =====================================================

    def validate_evidence(self, proposition):

        if proposition.kind != EpistemicType.FACT:
            return False

        if not proposition.evidence_ids:
            return False

        evidence_map = {
            item.id: item for item in self.evidence
        }

        for evidence_id in proposition.evidence_ids:

            item = evidence_map.get(evidence_id)

            if item is None:
                return False

            if not item.independently_verified:
                return False

        return True

    # =====================================================
    # 6. DETECTOR DE CONTRADICCIONES EXPLICITAS
    # =====================================================

    @staticmethod
    def canonicalize(content):

        text = content.casefold().strip()

        negated = False

        for prefix in ("no ", "not ", "nunca ", "jamás "):
            if text.startswith(prefix):
                negated = True
                text = text[len(prefix):]
                break

        return text, negated

    def detect_contradictions(self):

        self.contradictions = []

        for index, first in enumerate(self.propositions):

            for second in self.propositions[index + 1:]:

                a, neg_a = self.canonicalize(first.content)
                b, neg_b = self.canonicalize(second.content)

                if a == b and neg_a != neg_b:

                    self.contradictions.append({
                        "proposition_a": first.id,
                        "proposition_b": second.id,
                        "type": "EXPLICIT_NEGATION_CONFLICT",
                        "status": "UNRESOLVED"
                    })

        self.record(
            "CONTRADICTION_ANALYSIS",
            self.contradictions
        )

        return self.contradictions

    # =====================================================
    # 7. ANALISIS DE DEPENDENCIAS
    # =====================================================

    def analyze_dependencies(self):

        known_ids = {
            p.id for p in self.propositions
        }

        graph = {}

        for proposition in self.propositions:

            graph[proposition.id] = []

            for dependency in proposition.dependencies:

                if dependency not in known_ids:
                    raise ValueError(
                        f"UNKNOWN_DEPENDENCY: {dependency}"
                    )

                graph[proposition.id].append(dependency)

        visiting = set()
        visited = set()

        def visit(node):

            if node in visiting:
                raise ValueError("DEPENDENCY_CYCLE_DETECTED")

            if node in visited:
                return

            visiting.add(node)

            for dependency in graph[node]:
                visit(dependency)

            visiting.remove(node)
            visited.add(node)

        for node in graph:
            visit(node)

        self.dependencies = graph

        self.record("DEPENDENCY_GRAPH", graph)

        return graph

    # =====================================================
    # 8. VALIDACION DE INVARIANTES
    # =====================================================

    def invariant_check(self):

        results = {
            "I01_DATA_NE_FACT": True,
            "I02_HYPOTHESIS_NE_FACT": True,
            "I03_CLAIM_NE_FACT": True,
            "I04_EVIDENCE_REQUIRED_FOR_FACT": True,
            "I05_NO_UNRESOLVED_CONTRADICTION": True,
            "I06_DEPENDENCIES_VALID": True
        }

        for proposition in self.propositions:

            if proposition.kind == EpistemicType.FACT:

                if not self.validate_evidence(proposition):
                    results["I04_EVIDENCE_REQUIRED_FOR_FACT"] = False

        if self.contradictions:
            results["I05_NO_UNRESOLVED_CONTRADICTION"] = False

        try:
            self.analyze_dependencies()
        except ValueError:
            results["I06_DEPENDENCIES_VALID"] = False

        return results

    # =====================================================
    # 9. RECONSTRUCCION DEL CONOCIMIENTO
    # =====================================================

    def reconstruct(self):

        groups = {
            "OBJECTIVES": [],
            "FACTS": [],
            "CLAIMS": [],
            "ASSUMPTIONS": [],
            "HYPOTHESES": [],
            "CONSTRAINTS": [],
            "UNKNOWNS": []
        }

        mapping = {
            EpistemicType.OBJECTIVE: "OBJECTIVES",
            EpistemicType.FACT: "FACTS",
            EpistemicType.CLAIM: "CLAIMS",
            EpistemicType.ASSUMPTION: "ASSUMPTIONS",
            EpistemicType.HYPOTHESIS: "HYPOTHESES",
            EpistemicType.CONSTRAINT: "CONSTRAINTS",
            EpistemicType.UNKNOWN: "UNKNOWNS"
        }

        for proposition in self.propositions:
            groups[mapping[proposition.kind]].append(
                asdict(proposition)
            )

        return groups

    # =====================================================
    # 10. MOTOR DE DECISION
    # =====================================================

    def decide(self):

        invariants = self.invariant_check()

        if not all(invariants.values()):
            decision = Decision.HALT

        elif any(
            p.kind == EpistemicType.UNKNOWN
            for p in self.propositions
        ):
            decision = Decision.PROCESS

        else:
            decision = Decision.PROCESS

        return {
            "decision": decision.value,
            "invariants": invariants
        }

    # =====================================================
    # 11. EJECUCION COMPLETA
    # =====================================================

    def execute(self, input_data: list[str]):

        for item in input_data:
            self.add_proposition(item)

        contradictions = self.detect_contradictions()

        reconstruction = self.reconstruct()

        decision = self.decide()

        report = {
            "engine": VERSION,
            "decision": decision,
            "decomposition": reconstruction,
            "contradictions": contradictions,
            "dependencies": self.dependencies,
            "evidence": [
                asdict(e) for e in self.evidence
            ],
            "audit": self.audit
        }

        return report

# =========================================================
# 12. INTERFAZ DE EJECUCION
# =========================================================

if __name__ == "__main__":

    engine = GnousticDeconstructor()

    result = engine.execute([
        "Objetivo: identificar el problema.",
        "La arquitectura contiene siete capas.",
        "Hipótesis: el motor reduce la ambigüedad.",
        "Restricción: no ejecutar acciones sin autorización.",
        "Desconocido: rendimiento real del sistema."
    ])

    print(json.dumps(
        result,
        indent=2,
        ensure_ascii=False
    ))
```

### 4\. Reglas epistemológicas inmutables

El método se gobierna por estas cinco separaciones:

\\begin{aligned}
DATO &\\neq INFERENCIA\\\\
HIPÓTESIS &\\neq HECHO\\\\
AFIRMACIÓN &\\neq EVIDENCIA\\\\
PROPUESTA &\\neq AUTORIZACIÓN\\\\
EJECUCIÓN &\\neq VERIFICACIÓN
\\end{aligned}

### 5\. Condiciones de decisión

| Condición                                     | Resultado         |
| --------------------------------------------- | ----------------- |
| Estructura válida                             | PROCESS           |
| Información insuficiente                      | PROCESS + UNKNOWN |
| Contradicción sin resolver                    | HALT              |
| Evidencia insuficiente para declarar un hecho | REJECT / HALT     |
| Dependencia circular                          | HALT              |
| Invariante vulnerado                          | HALT              |

Nota técnica: el código es un prototipo funcional de descomposición. La clasificación lingüística y detección de contradicciones son heurísticas; no constituyen comprensión semántica completa ni verificación factual universal. La verificación requiere fuentes independientes adecuadas al dominio.
